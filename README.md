# УЛИЦА — фестиваль стрит-арта

Учебный сайт фестиваля уличного искусства: художники, выставки, экскурсии и мастер-классы 3–5 июля.

[Макеты в Figma](https://www.figma.com/design/XmQUREIvrHqs9ZGgfsup0U/) · [Готовый сайт](https://stasevdok.github.io/streetfest/)

Адаптивная вёрстка, программа с фильтрами по дням, «Мой план» с сохранением выбора, скачиванием PDF и копированием текста.

React + Vite, JavaScript и CSS. Интерфейс собран из переиспользуемых компонентов; данные вынесены отдельно, выбор хранится в localStorage. Публикация — GitHub Pages.
