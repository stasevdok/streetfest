# УЛИЦА — фестиваль стрит-арта

Учебный проект на React, Vite, JavaScript и обычном CSS по Figma:
https://www.figma.com/design/XmQUREIvrHqs9ZGgfsup0U/

## Запуск и сборка

Нужен Node.js 20+, рекомендуется 22+. В папке проекта:

```sh
npm install
npm run dev
npm run build
npm run preview
npm test
```

Адрес разработки: http://127.0.0.1:5173/ (при занятом порте Vite предложит другой).
Сборка находится в `dist`. На хостинге маршрут `/plan` должен возвращать `index.html`.

## Реализовано

- Семь разделов главной, оригинальные изображения Figma и локальный Inter 500/600/700.
- Первый экран занимает высоту окна. Фотография заполняет его на промежуточных ширинах.
- Прозрачная шапка и плавно появляющаяся белая шапка после прокрутки 76 px.
- Плавные переходы к разделам; меню телефона выезжает справа, закрывается вправо,
  блокирует фон, поддерживает Escape и удержание фокуса.
- Все девять художников, предоставленные социальные ссылки и иконки перехода.
  Стрелки листают ленту плавно; на телефоне работает свайп. Лента доходит до края экрана.
- «Программа»: все 16 событий сразу, фильтры всех дней и 3/4/5 июля, сортировка.
  Маркетинговая цифра «18 событий» сохранена по макету.
- Яндекс.Карта в iframe с предоставленным идентификатором: ширина контейнера,
  высота 660 px на компьютере и 500 px на планшете и телефоне.
- Уведомление об отсутствии регистрации по новому макету. Справа отступы
  40/20/10 px, на телефоне ширина окна минус 20 px. Через 4,5 секунды или по клику
  уведомление уезжает вправо.
- «Мой план» на `/plan`: уникальный выбор, группировка по дням, удаление,
  localStorage и восстановление позиции главной. Пустое состояние без кнопок.
- «Скачать план» формирует настоящий `ulitsa-my-plan.pdf` с кириллицей,
  встроенными шрифтами, исходным векторным логотипом, датами, временем, площадками и условиями входа.
  При переполнении создаются дополнительные страницы. PDF загружается отдельным
  модулем только при нажатии кнопки.
- «Скопировать текстом» помещает те же события в буфер обмена и показывает результат.
  Требуется разрешённый буфер обмена и HTTPS либо localhost.
- Неразрывные пробелы связывают короткие предлоги и союзы, даты и цены.
- Клавиатура, подписи иконок, focus-visible и отключение движения при системной
  настройке reduced motion.

## Как объяснить устройство на защите

`src/data.js` — общий список событий, художников и товаров. Для каждого события
указаны уникальный идентификатор, дни, время, название, площадка и условия входа.
Телефон, компьютер, программа и план используют этот один список.

`src/main.jsx` хранит массив выбранных идентификаторов. Добавление меняет массив,
а React обновляет кнопки, счётчик и план. Одно событие считается один раз,
даже когда проходит три дня. Выбор сохраняется в localStorage как JSON.
Неизвестные идентификаторы, дубликаты и повреждённые данные безопасно отбрасываются.

`src/components.jsx` содержит шапку, кнопки, карточки художников и товаров,
программу, карту, контакты, план и уведомления. `EventRow` используется и на главной,
и в плане: поэтому действие «Убрать» одинаково работает в обоих местах.

`src/plan.js` фильтрует события: выбранный день должен входить в массив дней события.
Затем события сортируются по дате и времени. Для плана добавляется проверка,
есть ли идентификатор в выборе пользователя. Эта же функция используется в PDF
и при сборке текста для копирования. Добавление в план не означает регистрацию.

`src/pdf.js` создаёт PDF средствами pdf-lib и встраивает локальный Inter.
Каждый выбранный день начинается на новой странице; длинные списки продолжаются
на следующей. `src/typography.js` обрабатывает только отображаемый текст.

`src/config.js` собирает все внешние адреса, включая карту и ссылки художников.
`src/styles.css` задаёт сетки, адаптив, кадрирование и переходы.
`public/assets` — исходные изображения и графика Figma.
`public/fonts` — Inter для PDF и лицензия OFL.
`verification` — снимки проверки и тестовый PDF со всеми событиями.

## Недостающие адреса

Не предоставлены URL регистрации на события, сообщества фестиваля в Telegram и ВК,
а также заказа мерча. В конфигурации они остаются пустыми; ссылки не выдуманы.

- Регистрация без URL показывает «Ссылки пока что нет / Добавим её чуть позже».
- В контактах у Telegram и ВК есть иконки по запросу, но до предоставления адресов
  названия остаются текстом. Почта `help@streetfest.ru` работает через mailto.
- Мерч остаётся витриной без ложных кнопок покупки.
- Все девять ссылок художников и карта подключены по предоставленным адресам.

## Проверка

`npm test` проверяет повреждённое хранилище, уникальность выбора, фильтрацию,
сортировку, многодневные события, текст для буфера обмена, структуру настоящего PDF,
его название, страницы, шрифты и браузерный Blob с правильным именем и типом.
Тестовый PDF также проверен извлечением кириллицы и визуальным просмотром страниц.

Адаптив проверяется на 1512, 1024, 768, 600, 470 и 375 px. Основной сценарий:
выбрать день → добавить несколько событий → открыть план → удалить многодневное
событие → перезагрузить → скачать PDF / скопировать → очистить план.

Встроенный браузер Codex не возвращает содержимое системного буфера после
`navigator.clipboard.writeText`; успешный вызов подтверждён уведомлением, передача
правильного текста отдельно проверена тестом. Сохранение файла в папку загрузок
этого браузера не подтверждено; генерация и содержимое PDF проверены независимо.

## GitHub Pages

Репозиторий: https://github.com/stasevdok/streetfest
Адрес после публикации: https://stasevdok.github.io/streetfest/

Публикация настроена в `.github/workflows/deploy.yml`: каждый push в `main`
запускает установку зависимостей, тесты, сборку и развёртывание GitHub Pages.
Источник публикации в Settings → Pages должен быть **GitHub Actions**.

Для Pages сборка получает `VITE_BASE_PATH=/streetfest/`. `src/paths.js` задаёт
адреса главной, плана и ресурсов относительно этой папки. Локальная разработка
по-прежнему работает в `/`. Скрипт `scripts/prepare-pages.mjs` создаёт отдельную
страницу `dist/plan/index.html`, поэтому план можно открыть напрямую и обновить.

Для проверки этой сборки локально:

```sh
VITE_BASE_PATH=/streetfest/ npm run build
node scripts/prepare-pages.mjs
VITE_BASE_PATH=/streetfest/ npm run preview
```

Откройте http://127.0.0.1:4173/streetfest/.
